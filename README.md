# Анализ воронки e-commerce | Product Analytics EDA (Python)

Сессионный анализ конверсионной воронки интернет-магазина:  
`page_view → add_to_cart → checkout → purchase`  
в разрезах по стране, возрасту, устройству и категории товара — плюс рейтинги и структура выручки.

**Домен:** E-commerce / Marketplace  
**Тип:** Product EDA · Funnel analysis · Segmentation  
**Стек:** Python, pandas

---

## Executive summary

**Проблема.** Понять, где ломается воронка покупки и есть ли просадки по сегментам пользователей или категориям товаров.

**Ключевые находки (уровень сессии):**
- Общий conversion **page_view → purchase ≈ 28%**.
- Главный отвал: **add_to_cart → checkout** (~45% сессий с товаром в корзине не доходят до оформления).
- Почти **нет различий** по стране, возрастной группе и устройству (скорее всего, из‑за синтетических данных).
- **Категория влияет на view → cart:** лучше всего Books / Toys / Beauty (~42–46%); **хуже всего Electronics (~24%)**.
- По выручке лидируют Home & Kitchen, Sports, Fashion; Books — часто покупают, но мало денег; Electronics — меньше позиций, выше средний чек.
- Рейтинги по категориям близки (~3.87–3.97); явно «токсичных» категорий нет. Electronics чуть слабее, отзывов меньше.

**Вывод для продукта.** В первую очередь улучшать сценарий **корзина → checkout** для всего трафика. Во вторую — разбирать **Electronics** на этапе просмотр → корзина. Точечные правки под мобильных, конкретную страну или возрастную группу на этих данных не опираются.

---

## Бизнес-проблема

Команде продукта и роста нужно ответить на два вопроса:

1. **Где и у кого проседает воронка**  
   `page_view → add_to_cart → checkout → purchase`  
   — в целом и в разрезах: страна, возраст, устройство, категория.

2. **Есть ли категории с систематически более низкими оценками?**  
   (В рамках проекта — только числовой `rating`; тональность текста отзывов — в следующих шагах.)

Без этого усилия распределяются «на всё подряд», а не на шаги и категории с наибольшим рычагом роста.

Проект отвечает на оба вопроса на мультитабличном датасете clickstream + транзакции, с явным учётом ограничений данных (отсутствие `product_id` на поздних шагах воронки, неполное покрытие отзывами, синтетика).

## Методология

| Решение | Выбор | Зачем |
|---------|--------|--------|
| Единица наблюдения | **Сессия** | Фокус на отвале внутри визита, а не на lifetime-поведении пользователя |
| Шаг пройден | ≥1 событие этого типа в сессии | Стандартное правило «хотя бы одно» для воронок |
| Полная воронка по категориям | **Не считается** | В `events` поле `product_id` на 100% пустое на `checkout` и `purchase` |
| View → cart по категориям | **Session + category** | Флаги на паре сессия–категория, затем агрегация |
| Структура покупок | orders + order_items + products | Выручка и объём по категориям |
| Рейтинги | Среднее, доля 1–2 и 4–5, число отзывов | Оценка качества с учётом объёма |
| Источник device | `sessions.device` | Поле заполнено полностью |

Возрастные группы: 18–24, 25–34, 35–44, 45–54, 55+.

## Результаты (подробнее)

### Общая воронка (сессии)

| Шаг | Сессии | CR от предыдущего | CR от начала |
|-----|--------|-------------------|--------------|
| page_view | 120 000 | 100% | 100% |
| add_to_cart | 81 518 | ~68% | ~68% |
| checkout | 44 909 | ~55% | ~37% |
| purchase | 33 580 | ~75% | **~28%** |

Главная «дыра»: **корзина → оформление заказа**.

### Сегменты (страна / возраст / устройство)

Конверсии отличаются на доли процентного пункта. Actionable-разрывов по сегментам на этих данных нет.

### Категории

**View → cart (session + category)**  
- Лучше: Books (~46%), Toys (~44%), Beauty (~42%)  
- Хуже: **Electronics (~24%)**  
- Середина: Fashion, Home & Kitchen, Sports (~33–37%)

**Покупки**  
- Лидеры по выручке: Home & Kitchen, Sports, Fashion (~17% каждая)  
- Books: наибольшая доля позиций (~21%), наименьшая доля выручки (~8%)  
- Electronics: мало позиций (~6%), заметная выручка (~14%) → выше средний чек

**Рейтинги**  
- Среднее ~3.87–3.97; доля оценок 1–2 ~10–13%  
- Electronics чуть ниже по среднему и выше по доле низких оценок; отзывов меньше (~690 против 1,1–2,3 тыс. у остальных)

## Рекомендации

1. **Приоритет №1 — сценарий cart → checkout (весь трафик)**  
   Гипотезы: неожиданная цена доставки, комиссии, трение формы оформления, доверие к оплате, обязательные поля.

2. **Приоритет №2 — Electronics на этапе просмотр → корзина**  
   Гипотезы: цена, сложность сравнения характеристик, слабые карточки товаров, потребность в большем research перед добавлением.

3. **Не размазывать усилия** по странам / возрасту / device — на этих данных сигнала нет.

4. **Рейтинги** сами по себе слабо приоритизируют категории; чтобы понять *почему* оценка низкая, нужен разбор текста отзывов.

---

## Ограничения

- Данные синтетические → слабая дифференциация по сегментам и рейтингам может быть артефактом генерации.  
- Нет `product_id` на checkout/purchase → нельзя честно построить полную категорийную воронку.  
- Отзывы оставляют не все покупатели (возможна смещённость в сторону недовольных).  
- Воронка считалась на уровне сессии («хотя бы одно событие»); интенсивность кликов внутри сессии не анализировалась.
